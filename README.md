# Himnario Cristiano para Jóvenes

🎵 Desarrollé este proyecto para uso personal y compartir con otros. 

🔗 [¡Disfruta!](https://himnariojovenes-lvez3kuhx-lucasortega2s-projects.vercel.app/)

📖 Este proyecto es un himnario que da un fácil acceso a letras de canciones cristianas.

---

## 📚 Secciones

### 🏠 Home Page:
- 🔗 Enlaces para ir al himnario o a la sección favoritos
- ➕ Botón para ir a la interfaz de gestión de himnos (con login)

### 📑 Listado de himnos:
- 📋 Listado de todos los himnos
- 🗂️ Inputs de búsqueda por categoría de himno
- 🔍 Input para buscar por nombre o número
- ❤️ Botones para agregar o quitar de favoritos
- 📄 Paginación

### ❤️ Listado de himnos favoritos:
- ✅ Mismas funciones que en la lista de himnos completa, solo que aparecen sólo los favoritos

### 🛠️ Gestión de himnos:
- ✏️ Interfaz intuitiva para agregar, editar o eliminar himnos
- 🔍 Input de búsqueda (idem que en listado de himnos)
- 🗂️ Input de categoría de himnario

---

## 🧰 Tecnologías

- 🧱 **Framework:** Astro con componentes de React  
- 🎨 **Style:** Tailwind  
- 🔐 **Auth:** Lucia Auth  
- 🗃️ **Base de datos:** Astro DB
